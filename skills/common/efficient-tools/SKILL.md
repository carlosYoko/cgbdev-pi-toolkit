# Uso eficiente de herramientas

- Usa codemode para filtrar, agregar o resumir resultados voluminosos antes de mostrarlos al modelo.
- Descubre herramientas cuando las necesites; no vuelques catálogos completos.
- Ejecuta en paralelo únicamente lecturas u operaciones independientes.
- Comprueba errores y truncamientos; no ocultes fallos importantes al resumir.
- Devuelve los datos necesarios para responder, con referencias para ampliar la consulta.
- No imprimas secretos, tokens ni variables de entorno completas.
- Para una operación sencilla, usa directamente la herramienta si resulta más claro.
- El sandbox de codemode no tiene Node, red ni acceso directo a archivos: usa las herramientas disponibles.
- No prometas un ahorro fijo de tokens; depende de la tarea y de los resultados.
